GitHub Gist sync

Create a token at github.com/settings/tokens with only the gist scope. The token and Gist ID are stored locally in this browser only — enter them again on each device/browser you use. They're only ever sent to api.github.com otherwise.

Syncs automatically a couple of seconds after any change, and "⟲ Sync" (popup or Library page) triggers one immediately.
